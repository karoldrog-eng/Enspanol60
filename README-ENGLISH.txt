ESPAÑOL 60 — English Edition

INSTALL / UPDATE (one upload)
1. Open https://github.com/karoldrog-eng/Enspanol60
2. Choose Add file → Upload files. Drag ALL FILES FROM INSIDE THIS ZIP (not the enclosing folder), then Commit changes.
3. Wait for GitHub Pages to deploy. Refresh https://karoldrog-eng.github.io/Enspanol60/ (close/reopen the installed PWA if needed).

WHAT'S INCLUDED
50 verb-focused lessons, 29 numbers lessons, 20 reading stories (~250 words each), text-to-speech, tap-to-glossary (common words), typed practice with rule-based error explanations, progress export/import, offline caching.

LIMITATIONS
This is a rule-based offline checker, not an AI tutor. It may reject alternative correct Spanish sentences. Word translations are available for selected glossary words, not every word. Number lessons use listening/digit recognition, but not all specialized number contexts are implemented. Story comprehension answers are self-checked. English translations should be reviewed as the curriculum is refined. Existing Polish course progress is retained in browser storage but is not automatically converted to the new curriculum.
